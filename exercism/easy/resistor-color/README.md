# Resistor Color Codes (TypeScript)

[Kata link](https://exercism.org/tracks/typescript/exercises/resistor-color)

## Notes

- Used a `readonly` array to store the color names in order.
- `colorCode` function uses `indexOf` to find the numeric value of a color.
- The order of the colors in the array determines their numeric values (black: 0, brown: 1, etc.).
