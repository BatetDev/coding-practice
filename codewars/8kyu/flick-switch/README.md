# Flick Switch (8 kyu)

[Kata link](https://www.codewars.com/kata/64fbfe2618692c2018ebbddb)

## Notes

- Used `map()` to transform each element into a boolean.
- Maintained a `flag` variable (starting as `true`) that toggles on `'flick'`.
- Returned the current `flag` value for every item, ensuring the switch persists across the array.
