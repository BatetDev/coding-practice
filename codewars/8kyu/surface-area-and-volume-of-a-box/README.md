# Surface Area and Volume of a Box (8 kyu)

[Kata link](https://www.codewars.com/kata/565f5825379664a26b00007c)

## Notes

- Used descriptive variable names for clarity: `surfaceArea` and `volume`.
- Surface area formula: `2 * (width * height + width * depth + height * depth)`.
- Volume formula: `width * height * depth`.
- Returned an array with surface area first, then volume, matching the expected output.
